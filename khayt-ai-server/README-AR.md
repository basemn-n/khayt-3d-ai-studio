# خيط 3D — إصدار AI المحسّن

## التشغيل على Windows
1. ثبّت Python 3.11 أو أحدث.
2. فك ضغط الحزمة إلى مجلد عادي على جهازك.
3. شغّل `run-windows.bat`. في أول تشغيل ينشئ بيئة Python وملف `.env` ويفتحه في المفكرة.
4. ضع مفتاح OpenAI API في `OPENAI_API_KEY` واحفظ الملف. لا تشارك هذا المفتاح ولا ترفعه إلى GitHub.
5. شغّل `run-windows.bat` مرة أخرى وانتظر تثبيت المكتبات وبدء الخادم. يفتح المتصفح على `http://127.0.0.1:8000`.
6. للتحقق من الخادم افتح `http://127.0.0.1:8000/health`. يجب أن تكون `ok: true` و`api_key_configured: true`.

## ربط الواجهة بخادم الذكاء الاصطناعي
- عند فتح نافذة «صمّم بالذكاء الاصطناعي»، اكتب في حقل «عنوان خادم الذكاء الاصطناعي» رابط خدمة الـ Web Service التي تشغّل هذا المجلد، مثل `https://khayt-3d-ai.onrender.com`، ثم اضغط «حفظ العنوان» و«اختبار الاتصال».
- لا تضع رابط Static Site أو رابط GitHub أو رابط لوحة Render. العنوان الصحيح يجب أن يعيد من `/health` بيانات JSON فيها `service: "khayt-ai"`.
- إذا كانت الواجهة منشورة على نطاق مختلف عن الخادم، أضف نطاق الواجهة إلى `CORS_ORIGINS` في إعدادات خدمة الخادم على Render، مثال: `https://your-frontend.onrender.com,http://localhost:8000`، ثم أعد نشر/تشغيل الخدمة.
- إذا ظهر رد XML أو HTML، فهذا يعني غالباً أن الطلب وصل إلى نطاق/مسار غير صحيح أو إلى صفحة خطأ وسيط؛ استخدم «اختبار الاتصال» لتحديد العنوان والرد الفعليين.

## الوظائف
- تصميم بالوصف العربي أو صورة مرجعية.
- تسجيل صوتي وتحويله إلى نص عربي.
- معاينة المقترح قبل إضافته للمشروع.
- تعديل الكائنات ونقاطها داخل المحرر، ثم محاكاة وفحص وتصدير DST.
- حفظ وفتح المشروع بصيغة JSON.

## النشر على Render
ارفع محتويات هذا المجلد إلى مستودع GitHub خاص. أنشئ Web Service بهذه الإعدادات:
- Build: `pip install -r requirements.txt`
- Start: `uvicorn main:app --host 0.0.0.0 --port $PORT`
- Environment: `OPENAI_API_KEY` و`OPENAI_MODEL=gpt-4.1` و`OPENAI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe`.
- إن استضفت الواجهة على نطاق آخر، أضف النطاق إلى `CORS_ORIGINS` مفصولاً بفواصل.
- لا ترفع ملف `.env` أو مفتاح API إلى المستودع.

## حدود مهمة قبل الإنتاج
هذه أداة تصميم ومساعدة أولية وليست رقمنة صناعية معتمدة. الذكاء الاصطناعي ينتج أشكالاً هندسية مبسطة، ومحرك التطبيق يحولها إلى غرز. يجب على فني تطريز مراجعة اتجاه الغرز، التداخل، التعويض عن شد القماش، كثافة التعبئة، ترتيب الألوان، نقاط القص والتوقف، ثم خياطة عينة فعلية. لا تعتمد ملف DST على قطعة إنتاج قبل اختباره على محاكي وبرنامج الماكينة.

## الأمان والخصوصية
مفتاح API يبقى على الخادم فقط. الصورة والتسجيل يرسلان إلى واجهة API عند ضغط المستخدم على إنشاء/تحويل. لا تحفظ الخدمة الصور أو التسجيلات على القرص. تكاليف API منفصلة عن اشتراك ChatGPT.
